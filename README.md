# 채권연령 분석기 (AR Aging Desk)

SAP 매출채권 미결항목 엑셀을 올리면 **연령분석 보고서**(요약 · 연령분석표 · 리스크 거래선 · 계정대사)를 만들어 주는 웹앱입니다.
파일은 **브라우저 안에서만** 처리되고 서버로 보내지 않습니다.

- 업로드 없이 **샘플 데이터로 바로 둘러보기** 가능 (가상의 거래선·금액, 시드 고정)
- 사이드바에서 **기준일**을 바꾸면 경과일·구간·충당금이 모두 다시 계산
- 금액 단위 **원 / 백만원 / 억원** 전환
- 결과를 **엑셀 10개 시트**로 내보내기: 요약, 내수 연령분석, 수출 연령분석, 공시용, 전분기비교, 리스크분석, 계정대사, 제외항목, 데이터점검, 채권원장분석

## 실행

빌드가 필요 없는 정적 사이트입니다.

- **바로 열기**: `index.html`을 더블클릭 (엑셀 라이브러리를 CDN에서 받으므로 인터넷 연결 필요)
- **로컬 서버**: 폴더에서 `python -m http.server 5178` 실행 후 `http://localhost:5178`
- **테스트**: `tests.html`을 열면 엔진 단위 테스트 20개가 실행됨 (샘플 기준 10개 계정 대사 차이 0 포함)
- **배포**: 폴더를 그대로 GitHub Pages(저장소 Settings → Pages → 브랜치 루트) 또는 Vercel에 올리면 됨

## 화면

| 화면 | 내용 |
|---|---|
| 시작 | 드롭존, 필요한 시트 안내, 샘플로 둘러보기, 샘플 엑셀 받기 |
| 요약 보고 | KPI 4개(총 채권 · 120일 이상 비중 · 충당금 · DSO), 연령 구성 막대(당분기/전분기), 주요 이슈 3개, 권고사항, 구간별 증감표 |
| 연령분석표 | 내수/수출 탭, 구간 합계 스트립, 거래선별 표 + 분포 미니바, 거래선 검색, 공시용 연령표 |
| 리스크 거래선 | 120일 이상 거래선(신규/증가/감소/해소/동일), 여신한도 초과, DSO, 관리등급 조정 의견 |
| 대사 · 데이터 점검 | RAW → 제외 → 외화평가 → 분석대상 vs 시산표, 데이터 점검 결과, 제외 항목, 적용 기준 |

| 기준정보 | 권장 | 기준일, 계정 매핑, PayT 규칙, 기말환율, 충당금 설정률, 분기 매출액 |

- 머리글 행은 앞쪽 20행 안에서 자동으로 찾습니다. 열 이름의 공백·괄호·하이픈 차이는 무시합니다.
- **기준정보**는 표 여러 개가 옆으로 붙은 형태를 그대로 읽습니다. `계정코드`, `PayT`, `통화`, `설정률`, `매출액` 머리글 칸을 찾아 각각 아래로 읽습니다.
- 기준정보·시산표·전분기 시트가 없으면 기본값으로 계산하고 화면 상단에 무엇을 대신했는지 알려 줍니다.
- 정확한 양식은 시작 화면의 **샘플 엑셀 받기**로 확인할 수 있습니다.

## 처리 기준

1. **포함 여부**: 반제일 ≤ 기준일이면 제외(이미 회수됨). 증빙일 > 기준일이면 제외.
2. **재분류**: 대분류가 미수금이고 텍스트에 "제품매출"이 있으면 외상매출금 국판으로 옮겨 연령분석에 포함. 시산표 대사는 원계정 기준 유지.
3. **외화 환산**: 통화가 KRW가 아닌 화폐성 계정은 `전표통화금액 × 기말환율`. 선수금은 비화폐성이라 환산하지 않음.
4. **만기일**: 순만기일 우선. 없으면 PayT(비면 지급조건-마스터) 규칙으로 산정 — 월말 기산은 증빙월 말일 + 일수, 증빙일 기산은 증빙일 + 일수.
5. **발생기준 구간**: 기준일 − 증빙일 → 29일 이하 / 30~59 / 60~89 / 90~119 / 120일 이상.
6. **공시용 구간**: 만기일 기준 → 만기미도래 / 3개월 이하 / 3~6개월 / 6~12개월 / 12개월 초과 / 만기없음 (달력 월).
7. **충당금**: 구간별 설정률, 단 관리등급 부실 50% · 대손 100% 우선. 음수·선수금·거래선 없는 항목은 0.
8. **여신한도 초과**: 거래선별 매출채권 잔액(선수금 차감 없음) > 여신한도.
9. **등급 불일치**: 정상인데 120일 이상 비중 20% 이상 → 주의, 50% 이상 → 부실. 주의인데 120일 이상 없고 만기경과 10% 미만 → 정상. 부실·대손인데 59일 이하 비중 50% 이상 → 재검토.
10. **DSO**: 소분류 잔액 ÷ (분기 매출액 ÷ 91).
11. **데이터 점검**: 기준일 이전 반제, 제품매출 오분류, 순만기일 누락, PayT 누락, 마스터 미등록 거래선, 거래선명 불일치(㈜/공백), 음수 채권, 거래선 없음.

## 판단 근거

- **반제일 기준으로 제외** — SAP 미결항목은 추출 시점 기준이라, 기준일 이후에 뽑으면 기준일 전에 이미 회수된 전표가 섞입니다. 기준일 현재 잔액만 남겨야 시산표와 맞습니다. 반대로 기준일 뒤에 반제된 건은 기준일 현재 미결이므로 포함합니다.
- **선수금은 환산하지 않음** — 선수금은 재화·용역으로 갚는 비화폐성 부채라 기말환율로 다시 평가하지 않습니다(K-IFRS 1021). 환산하면 시산표와 어긋납니다.
- **재분류는 분석에서만** — 제품매출이 미수금으로 잡혔다면 실질은 매출채권이라 연령분석·충당금 대상에 넣어야 하지만, 장부를 고친 것은 아니므로 시산표 대사는 원계정 그대로 맞춥니다. 대사표의 "재분류로 나간 금액" 열로 추적합니다.
- **발생기준과 공시용을 둘 다** — 내부 관리는 거래 발생 후 경과일(회수 지연의 체감 지표)로, 공시는 만기 경과 기준으로 요구되므로 두 표를 함께 냅니다.
- **등급 우선 충당금** — 부실·대손 거래선은 연령과 무관하게 회수 가능성이 낮으므로 개별 평가율을 구간률보다 우선합니다. 음수(반품·할인)는 충당 대상이 아니라 0으로 둡니다.
- **여신 사용액에서 선수금 미차감** — 선수금은 거래선별로 정산 시점이 달라 채권과 상계를 보장할 수 없으므로 보수적으로 매출채권 잔액만 봅니다.

## 구조

```
index.html      화면 진입점
styles.css      디자인 토큰·공통 스타일 (IBM Plex Sans KR / Mono)
tests.html      엔진 단위 테스트(브라우저에서 실행)
js/engine.js    계산 로직 — 순수 함수, DOM 없음 (과제 엑셀로 검증된 원본)
js/parser.js    엑셀 → 분석 입력(시트 찾기, 머리글 탐색, 기준정보 위치 탐색, 기본값)
js/sample.js    샘플 데이터 생성기(가상 거래선, 시드 고정) + 샘플 엑셀 저장
js/report.js    이슈·권고사항·증감 원인 등 보고서 문구
js/export.js    엑셀 10개 시트 내보내기
js/app.js       화면 렌더링·이벤트
```

외부 의존성은 엑셀 처리용 [SheetJS](https://sheetjs.com) 하나이며, 차트는 CSS로 직접 그립니다.
